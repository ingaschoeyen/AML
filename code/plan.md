# Project Plan: Code


The purpose of the system is to produce a representation of the data in the archives that allows for efficient search and interaction with the data.
The system consists of three main components:

- Data Production: 
    - extracts the data from the archives
    - assigns metadata where possible 
    - creates embeddings in a vector space and a graph structure
- Backend: 
    - storage of the extracted data and embeddings
    - register linking to the original data in the archives
    - search engine for querying the data
- UI:
    - search interface for querying the data
    - map interface for visualizing the data on a geographical map
    - graph interface for visualizing the relationships between the data
